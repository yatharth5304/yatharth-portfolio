FoodFinder

Spring Boot, PostgreSQL, REST APIs, geolocation

Problem

Discovering local food options is fragmented across multiple apps and hard to filter meaningfully. Users need a single, fast interface with geolocation awareness.

Built

A full-stack food discovery platform with smart search, category filters, geolocation-based sorting, and a responsive UI backed by Spring Boot and PostgreSQL.

Engineering Challenge

Search needs to remain responsive while filtering by category, location, and keyword without unnecessary database overhead.
