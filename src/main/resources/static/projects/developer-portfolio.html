Developer Portfolio

Spring Boot, PostgreSQL, REST APIs, Flyway, Docker

Problem

My personal developer portfolio built with a Spring Boot backend served as a REST API and a responsive frontend, demonstrating real backend architecture rather than a static file.

Built

This site uses a Spring Boot REST API, PostgreSQL backend, Flyway-managed schema, an admin panel for content management, Docker containerisation, and Render deployment.

Engineering Challenge

Free-tier cold starts on Render can cause multi-second spin-up delays. The portfolio uses skeleton loaders and background wake-up pings so perceived loading remains responsive.
