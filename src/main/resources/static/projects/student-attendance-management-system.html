Project · Yatharth Maharwade

Student Attendance Management System

Java, Spring Boot, PostgreSQL, REST APIs, RBAC

Problem

Manual attendance tracking is error-prone and provides little real-time visibility to faculty or administrators.

Built

A multi-role web application with scoped dashboards: administrators see institution-wide data, faculty manage assigned classes, and students track their attendance.

Engineering Challenge

The RBAC model keeps data-scope enforcement in the service layer so roles cannot access another role's data.
