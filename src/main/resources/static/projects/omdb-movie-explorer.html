OMDB Movie Explorer

Spring Boot, JavaScript, JWT, OMDB API

Problem

There was a need for a focused interface to search and explore movie data from the OMDB catalog without a cluttered experience.

Built

Movie discovery UI with real-time search, detail views, session-based favourites, JWT authentication, and client-side caching.

Engineering Challenge

The application handles OMDB API rate limits and JWT authentication in a stateless Spring Boot setup.
