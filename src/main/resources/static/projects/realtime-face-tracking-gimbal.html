Project · Yatharth Maharwade

Realtime Face Tracking Gimbal

OpenCV, CNN, Python, computer vision, servo motors

Problem

Static cameras can lose subjects in dynamic environments. This project physically follows a face in real time without manual camera control.

Built

A computer vision pipeline detects faces per frame and drives servo motors through serial commands to keep the subject centred.

Engineering Challenge

Frame processing is decoupled from motor control to reduce actuation lag caused by blocking I/O.
